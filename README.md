## 📊 Project Overview

This is an end-to-end **Blinkit Data Analytics Project** built using **Python, Pandas, and Power BI**.

The project starts with raw Blinkit order data, performs data cleaning and feature engineering using Python, exports the final cleaned dataset to CSV, and then uses Power BI to build an interactive business dashboard.

The analysis focuses on:

- Sales performance
- Product performance
- Brand performance
- Pricing and discounts
- Customer orders
- Payment methods
- Delivery performance
- Delivery partners
- City-level performance
- Quantity analysis

The main goal of this project is to transform raw transactional data into meaningful business insights through data cleaning, analysis, and visualization.
